Quick Start

Guide du Maître du Jeu

Défi Hygiène & Sécurité Alimentaire · Mode Live

Accès https://pierrre2db.github.io/qcm-v2/
ÉTAPE 1
🌐
Ouvrez l'appli
Allez sur l'URL ci-dessus depuis votre ordinateur. Connectez-vous au projecteur.
ÉTAPE 2
📋
Créez une session
Descendez jusqu'à Espace Enseignant → cliquez "Créer une session live".
ÉTAPE 3
📱
Joueurs se connectent
Ils scannent le QR code ou tapent l'URL + le code à 6 lettres affiché en grand.
ÉTAPE 4
🚀
Lancez la partie !
Quand tout le monde est prêt → cliquez "Lancer la partie".
📲
Comment les joueurs rejoignent sur mobile
Option A — QR code : Scanner le QR code affiché sur votre écran → arrive directement sur la page de connexion.
Option B — URL : Taper pierrre2db.github.io/qcm-v2 → entrer le code de salle.
?room=XXXXXX
Pendant la partie — ce que vous voyez sur votre tableau de bord
Joueur n'a pas encore répondu
Réponse correcte ✓
Réponse incorrecte ✗
Bouton "Question suivante" → avancer sans attendre le timer
