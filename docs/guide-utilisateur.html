02

Mode Entraînement Solo — Pratiquer à son rythme

🎯
Idéal pour tester ses connaissances avant ou après une formation, sans pression et sans formateur.

Comment démarrer ?

  1. Ouvrir l'application sur votre téléphone ou ordinateur
  2. Entrer votre prénom
  3. Choisir votre avatar — Robot 🤖 · Emoji 😄 · Pixel 🎮
  4. Cliquer sur "S'entraîner seul" — aucun code requis
  5. Le quiz démarre immédiatement

Pendant le quiz

  • Les questions s'affichent une par une, avec 3 choix de réponse (A, B, C)
  • Pas de chronomètre qui décompte — vous répondez à votre rythme
  • Un compteur de temps tourne en fond (pour information, sans pression)
  • Après chaque réponse, la question suivante s'affiche directement
⚠️
Pas de correction entre les questions — la correction complète arrive à la fin du quiz.

À la fin du quiz — Votre résultat

Vous obtenez votre note sur 10 et votre groupe de niveau :

GroupeSignification
🏆 ExpertMaîtrise complète — félicitations !
✅ BienBonne base, quelques points à revoir
⚠️ AméliorableDes lacunes sur des points importants
🔴 À revoirRévision approfondie recommandée

Vous voyez aussi votre temps total, votre pourcentage de réussite et un commentaire personnalisé du formateur selon votre score.

La correction détaillée

Cliquez sur "Revoir les réponses" pour accéder à la correction complète :

  • Chaque question avec votre réponse
  • La bonne réponse si vous vous êtes trompé
  • Une explication pédagogique pour comprendre pourquoi

Cliquez "Recommencer" pour refaire le quiz et améliorer votre score.

03

Mode Live — Le vécu du joueur

🎮
Tout le monde joue en même temps. L'animateur contrôle le rythme. L'ambiance est celle d'un jeu télévisé.

Comment rejoindre la session ?

  1. Ouvrir l'application sur son téléphone ou ordinateur
  2. Entrer son prénom
  3. Choisir son avatar — Robot 🤖 · Emoji 😄 · Pixel 🎮
  4. Entrer le code à 6 caractères donné par le formateur 27Z6LC
  5. Cliquer "Rejoindre la session"
💡
Pas besoin de créer un compte. Juste un prénom et le code de salle.

La salle d'attente

Après avoir rejoint, vous arrivez dans la salle d'attente. Vous voyez votre avatar, les autres participants qui arrivent, et un message "En attente du démarrage…"

La session démarre quand le formateur clique sur "Lancer la partie".

Les 4 boutons de réponse

▲ Réponse A
◆ Réponse B
● Réponse C
■ Réponse D

Pendant le quiz

  • Les questions apparaissent en même temps pour tout le monde
  • Un timer de 30 secondes décompte — il faut répondre avant la fin !
  • Dès que vous cliquez une réponse, vous passez en mode "En attente"
  • Vous ne pouvez pas changer votre réponse

Entre chaque question

Un écran d'attente s'affiche pendant que les autres finissent de répondre. La question suivante apparaît dès que le formateur avance.

À la fin

Votre score final s'affiche. Le formateur peut afficher le classement général et le podium des meilleurs scores.

04

Mode Live — Le tableau de bord du Maître du Jeu

👨‍🏫
Le formateur voit tout en temps réel. Il contrôle le rythme de la session depuis son écran — idéalement projeté pour le groupe.

Créer une session

  1. Ouvrir l'application
  2. Aller dans "Espace Enseignant"
  3. Sélectionner un quiz
  4. Cliquer "Créer une session"
  5. Un code à 6 caractères est généré automatiquement → le donner aux participants

L'écran de lobby — avant le démarrage

  • Le code de salle affiché en grand (à projeter ou dicter)
  • Les avatars des joueurs qui apparaissent en temps réel
  • Quand tout le monde est là → cliquer "Lancer la partie"

Pendant le quiz — la grille des joueurs en temps réel

05

Déroulement complet d'une session live

Voici comment se déroule une session de A à Z :

AVANT LA SESSION
─────────────────────────────────────────────────────
Formateur → Crée la session → obtient le code « 27Z6LC »
Formateur → Projette ou dicte le code aux participants

CONNEXION DES JOUEURS
─────────────────────────────────────────────────────
Joueurs → Ouvrent l'app sur leur téléphone
Joueurs → Entrent prénom + avatar + code
Formateur → Voit les avatars apparaître en temps réel
✓ Attendre que tout le monde soit connecté

DÉMARRAGE
─────────────────────────────────────────────────────
Formateur → Clique "Lancer la partie"
Joueurs → La 1ère question s'affiche automatiquement

POUR CHAQUE QUESTION (×10)
─────────────────────────────────────────────────────
Joueurs → Lisent la question · Timer 30s démarre
Joueurs → Cliquent une réponse → passent en attente
Formateur → Voit les avatars passer au vert ✓ / rouge ✗
Formateur → Clique "Question suivante" quand prêt

FIN DE SESSION
─────────────────────────────────────────────────────
Formateur → Clique "Terminer"
Joueurs → Voient leur score final
Formateur → Voit le classement complet + podium

Conseils pour une session réussie

  • 📶 Vérifier que tous les participants ont une connexion internet avant de commencer
  • 📺 Projeter votre écran (tableau de bord) pour que le groupe vive la session ensemble
  • ⏱️ Prévoir 2-3 minutes de connexion avant de lancer la partie
  • 🔁 Les joueurs peuvent rejouer en solo après la session pour consolider leurs acquis
  • 🎯 Utiliser le mode Solo comme devoir de préparation avant la session live
