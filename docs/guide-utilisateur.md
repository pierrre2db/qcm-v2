# Guide Utilisateur — QCM V2
## Défi Hygiène & Sécurité Alimentaire

> Document à destination des formateurs et apprenants. Aucune connaissance technique requise.

---

## 1. Vue d'ensemble — Deux façons d'utiliser l'application

Que vous soyez seul chez vous ou en salle de formation avec un groupe, l'application s'adapte à votre situation. Les mêmes questions, deux expériences différentes.

| | 📱 Mode Solo | 🎮 Mode Live |
|---|---|---|
| Qui l'utilise ? | Un apprenant seul | Un groupe + un animateur |
| Quand ? | À tout moment, à son rythme | Pendant une session de formation |
| Besoin d'internet ? | Oui (chargement) | Oui (connexion en temps réel) |
| Résultat immédiat ? | Oui, à la fin du quiz | Oui, à la fin de la session |
| Correction détaillée ? | Oui, question par question | Via l'animateur |

> 💡 **En résumé :** Le mode Solo, c'est réviser son cours tranquillement. Le mode Live, c'est l'interro en classe — tout le monde répond en même temps, l'animateur voit tout.

---

## 2. Mode Entraînement Solo — Pratiquer à son rythme

> 🎯 Idéal pour tester ses connaissances avant ou après une formation, sans pression et sans formateur.

### Comment démarrer ?

1. Ouvrir l'application sur votre téléphone ou ordinateur
2. Entrer votre prénom
3. Choisir votre avatar (Robot 🤖 / Emoji 😄 / Pixel 🎮)
4. Cliquer sur **"S'entraîner seul"** — aucun code requis
5. Le quiz démarre immédiatement

### Pendant le quiz

- Les questions s'affichent une par une, avec **3 choix de réponse** (A, B, C)
- **Pas de chronomètre** qui décompte — vous répondez à votre rythme
- Un compteur de temps tourne en fond (pour info, sans pression)
- Après chaque réponse, la question suivante s'affiche directement
- ⚠️ Pas de correction entre les questions — la correction complète arrive à la fin

### À la fin du quiz — Votre résultat

Vous obtenez votre **note sur 10** et votre **groupe de niveau** :

| Groupe | Signification |
|---|---|
| 🏆 Expert | Maîtrise complète |
| ✅ Bien | Bonne base, quelques points à revoir |
| ⚠️ Améliorable | Des lacunes sur des points importants |
| 🔴 À revoir | Révision approfondie recommandée |

Vous voyez aussi votre **temps total** et votre **pourcentage de réussite**.

### La correction détaillée

Cliquez sur **"Revoir les réponses"** pour accéder à la correction complète :
- Chaque question avec votre réponse
- La bonne réponse si vous vous êtes trompé
- Une **explication pédagogique** pour comprendre pourquoi

Vous pouvez ensuite cliquer **"Recommencer"** pour refaire le quiz et progresser.

## 3. Mode Live — Le vécu du joueur

> 🎮 Tout le monde joue en même temps. L'animateur contrôle le rythme. L'ambiance est celle d'un jeu télévisé.

### Comment rejoindre la session ?

1. Ouvrir l'application sur son téléphone ou ordinateur
2. Entrer son prénom
3. Choisir son avatar (Robot 🤖 / Emoji 😄 / Pixel 🎮)
4. Entrer le **code à 6 caractères** donné par le formateur (ex : `27Z6LC`)
5. Cliquer **"Rejoindre la session"**

> 💡 Pas besoin de créer un compte. Juste un prénom et le code de salle.

### La salle d'attente

Après avoir rejoint, vous arrivez dans la **salle d'attente**. Vous voyez :
- Votre avatar et votre prénom
- Les autres participants qui arrivent au fur et à mesure
- Un message "En attente du démarrage…"

La session démarre quand le formateur clique sur **"Lancer la partie"**.

### Pendant le quiz

- Les questions apparaissent **en même temps pour tout le monde**
- **4 boutons colorés** pour répondre : ▲ Rouge · ◆ Bleu · ● Jaune · ■ Vert
- Un **timer de 30 secondes** décompte — il faut répondre avant la fin !
- Dès que vous cliquez une réponse, vous passez en mode **"En attente"**
- Vous ne pouvez pas changer votre réponse

### Entre chaque question

Un écran d'attente s'affiche pendant que les autres finissent de répondre. La question suivante apparaît dès que le formateur avance.

### À la fin

Votre score final s'affiche. Le formateur peut afficher le classement général.

## 4. Mode Live — Le tableau de bord du Maître du Jeu

> 👨‍🏫 Le formateur voit tout en temps réel. Il contrôle le rythme de la session depuis son écran.

### Créer une session

1. Ouvrir l'application
2. Aller dans **"Espace Enseignant"**
3. Sélectionner un quiz
4. Cliquer **"Créer une session"**
5. Un **code à 6 caractères** est généré automatiquement → le donner aux participants

### L'écran de lobby (avant le démarrage)

Le formateur voit :
- Le **code de salle** en grand (à projeter ou dicter)
- Les **avatars des joueurs** qui rejoignent en temps réel
- Le nombre de participants connectés

Quand tout le monde est prêt → cliquer **"Lancer la partie"**.

### Pendant le quiz — tableau de bord en temps réel

Pour chaque question, le formateur voit :
- La **question en cours** et les 4 réponses possibles (avec la bonne réponse mise en évidence)
- Un **timer circulaire** qui décompte les 30 secondes
- Les **statistiques en direct** : combien ont répondu, combien attendent
- La **grille des joueurs** avec leurs avatars colorés :
  - 🔘 Gris = n'a pas encore répondu
  - 🟢 Vert = a répondu correctement ✓
  - 🔴 Rouge = a répondu incorrectement ✗

### Contrôles disponibles

| Bouton | Action |
|---|---|
| **Question suivante** | Passer à la question suivante sans attendre le timer |
| **Arrêter la session** | Terminer la partie avant la fin |

### À la fin de la session

Un écran récapitulatif s'affiche avec les scores. Le formateur peut choisir d'afficher le podium final aux joueurs.

## 5. Déroulement complet d'une session live (étape par étape)

Voici comment se déroule une session de A à Z.

```
AVANT LA SESSION
─────────────────────────────────────────────────────
  Formateur  →  Crée la session → obtient le code "27Z6LC"
  Formateur  →  Projette ou dicte le code aux participants

CONNEXION DES JOUEURS
─────────────────────────────────────────────────────
  Joueurs    →  Ouvrent l'app sur leur téléphone
  Joueurs    →  Entrent leur prénom + avatar + code
  Formateur  →  Voit les avatars apparaître en temps réel
                ✓ Attendre que tout le monde soit connecté

DÉMARRAGE
─────────────────────────────────────────────────────
  Formateur  →  Clique "Lancer la partie"
  Joueurs    →  La 1ère question s'affiche automatiquement

POUR CHAQUE QUESTION (×10)
─────────────────────────────────────────────────────
  Joueurs    →  Lisent la question · Timer 30s démarre
  Joueurs    →  Cliquent une réponse → passent en attente
  Formateur  →  Voit les avatars passer au vert / rouge
  Formateur  →  Clique "Question suivante" quand prêt

FIN DE SESSION
─────────────────────────────────────────────────────
  Formateur  →  Clique "Terminer"
  Joueurs    →  Voient leur score final
  Formateur  →  Voit le classement complet + podium
```

### Conseils pour une session réussie

- 📶 Vérifier que tous les participants ont une connexion internet
- 📺 Projeter votre écran (tableau de bord) pour que le groupe vive la session ensemble
- ⏱️ Prévoir 2-3 minutes de connexion avant de lancer
- 🔁 Les joueurs peuvent rejouer en solo après la session pour s'améliorer
